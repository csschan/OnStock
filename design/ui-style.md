# UI设计规范

## 设计原则
- 亮色为主，干净简洁
- 大量留白，不堆砌信息
- 专业金融感，不是crypto风格
- 参考: Linear, Stripe, Revolut

## 配色方案

### 主色调
- 背景: #FFFFFF (纯白)
- 次级背景: #F8FAFC (浅灰白，卡片/区块背景)
- 边框: #E2E8F0 (淡灰)

### 文字
- 主文字: #0F172A (深黑)
- 次文字: #64748B (灰色)
- 弱文字: #94A3B8 (浅灰)

### 强调色
- 主色: #2563EB (蓝色，按钮/链接)
- 主色悬停: #1D4ED8
- 成功/涨: #16A34A (绿色)
- 警告/跌: #DC2626 (红色)
- 推荐标签: #EFF6FF 背景 + #2563EB 文字

### 渐变 (少用，仅Banner)
- Hero背景: #F8FAFC → #FFFFFF

## 字体
- 英文: Inter
- 数字/价格: JetBrains Mono (等宽)
- 字号: 14px正文 / 16px标题 / 24px大标题 / 32px Hero

## 圆角
- 按钮: 8px
- 卡片: 12px
- 输入框: 8px

## 阴影
- 卡片: 0 1px 3px rgba(0,0,0,0.05)
- 悬停: 0 4px 12px rgba(0,0,0,0.08)
