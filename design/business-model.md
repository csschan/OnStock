# 商业模式

## 收入来源

### 1. 交易手续费 (主要收入)
- 用户通过平台执行交易时收取 0.1%-0.3%
- 仅对平台内交易收取 (DEX swap / 发行商铸造赎回)
- CEX跳转不收费

| 交易金额 | 费率 |
|---------|------|
| < $1,000 | 0.3% |
| $1,000 - $10,000 | 0.2% |
| > $10,000 | 0.1% |

### 2. 推荐佣金
- 部分发行商有Referral Program
- 通过平台导流到发行商的交易可获得返佣
- 预计占收入 15-20%

### 3. API订阅 (后期)
- 比价API开放给第三方DApp使用
- 免费: 100次/天
- Pro: $49/月, 10,000次/天
- Enterprise: 定制

### 4. 高级功能订阅 (后期)
- 定投自动化: $9.9/月
- 套利实时监控: $19.9/月
- 高级数据分析: $29.9/月

## 成本结构

### 固定成本 (每月)
| 项目 | 费用 |
|------|------|
| VPS服务器 | $20-50 |
| 域名 | ~$1 |
| RPC节点 (免费额度用完后) | $0-100 |
| **总计** | **$21-151** |

### 变动成本
- 无额外变动成本 (交易Gas由用户承担)

### 人力成本
- 早期: 创始人全职开发
- 后期: 视收入情况招人

## 盈亏平衡

```
月固定成本: ~$50 (MVP阶段)
平均手续费率: 0.2%
盈亏平衡交易额: $50 / 0.002 = $25,000/月
即每天 ~$830 的交易额就能覆盖成本
```

**门槛极低, 几乎从上线第一天就能盈利。**
