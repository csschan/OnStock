## 间接竞品

### 1. 1inch (DEX聚合器)
- **网站**: https://1inch.io
- **做了什么**: 接入Ondo, 通过Swap API路由美股代币交易, 累计$25亿交易量
- **没做什么**: 只接了Ondo一家, 没有跨发行商比价, 没有美股专属UI
- **我们的差异**: 全发行商比价 + 美股专属体验 + 买卖双向 + 发行商信息对比

### 2. Bitget Wallet (DEX聚合器)
- **做了什么**: DEX聚合器API支持RWA市价单, 首个支持RWA市价单的聚合器
- **没做什么**: 只是交易执行层, 没有比价UI, 没有美股专属功能
- **我们的差异**: 面向终端用户的比价产品, 不是API

### 3. Jupiter (Solana聚合器)
- **网站**: https://jup.ag
- **做了什么**: Solana上最大的DEX聚合器, 可以swap Backed的美股代币
- **没做什么**: 仅限Solana, 无跨链, 无美股专属功能
- **我们的差异**: 跨链 + 跨发行商 + 美股专属

### 4. DexScreener
- **网站**: https://dexscreener.com
- **做了什么**: 展示DEX上的美股代币交易对信息和图表
- **没做什么**: 只是数据展示, 不做比价, 不做交易, 不区分发行商
- **我们的差异**: 主动比价 + 交易执行 + 发行商信息

### 5. RWA.xyz
- **网站**: https://rwa.xyz
- **做了什么**: RWA数据分析平台, 展示代币化股票市场数据
- **没做什么**: 只是数据/分析, 不做交易, 不做比价
- **我们的差异**: 面向交易用户, 不是分析师

## 发行商自有平台

| 发行商 | 自有交易 | 局限性 |
|--------|---------|--------|
| Ondo | ondo.finance 可铸造/赎回 | 只有自己的代币, 用户不知道是否最优价 |
| Backed | backed.fi 可铸造/赎回 | 同上 |
| Dinari | dinari.com 可购买 | 同上 |
| Kraken | kraken.com 可交易 | CEX, 需KYC, 无法比较链上DEX价格 |

**用户痛点**: 每个发行商都说自己最好, 用户没有统一的地方做比较

## 我们的竞争优势

1. **唯一的跨发行商比价工具** — 市场空白
2. **买入+卖出双向** — 不只帮你买便宜的, 也帮你卖到最多
3. **平台内交易** — DEX swap直接完成, 不用跳转
4. **美股专属体验** — 不是通用DEX聚合器, 专为美股代币设计
5. **先发优势** — 第一个做的定义品类
